# Zed Configuration

My personal Zed settings, keymaps, tasks, and what not I've configured on my Zed IDE. Simply clone the repository into your Zed configuration directory:

#### Linux/Mac

```bash
git clone https://github.com/yourusername/Zed.git ~/.zed
```

#### Windows

```bash
git clone https://github.com/yourusername/Zed.git %USERPROFILE%\AppData\Roaming\Zed
```
